サブスク・アカウント管理

プライバシーポリシー

制定日：2026年11月5日

サブスク・アカウント管理（以下「本アプリ」）は、開発者本人が自分の PC で使うための個人用アプリです。このページでは、本アプリが扱う情報とその取り扱いを説明します。

1. Google から取得する情報

  • 基本情報：ログインの確認に使う、メールアドレス、名前、プロフィール画像
  • Gmail（読み取りのみ）：メールの送信元、件名、受信日時、本文。メールの送信、変更、削除はしません。
  • Google カレンダー：予定の読み取りと、利用者が操作したときの予定の追加、削除

2. 利用目的

サブスク、アカウント登録、予定、カード利用額を読み取り、一覧や集計として利用者本人に表示するためだけに使います。広告には使わず、情報を販売することもありません。

3. 保存する情報と保存場所

次の情報を、利用者の PC 内のデータベースに保存します。開発者が運営する外部サーバーはありません。

  • メールの送信元、件名、受信日時（メール本文は保存しません）
  • メールから読み取ったサブスク、アカウント登録、予定の提案
  • カードの利用先、金額、利用日、月ごとの請求額
  • Google アカウントの基本情報（メールアドレス、名前、プロフィール画像）
  • Google へのアクセスに使うログイン情報（アクセストークン、更新トークン）

4. 外部サービスへの送信

  • Anthropic（AI「Claude」）：メールの分類と項目の読み取りのため、送信元、件名、受信日、本文（1通につき先頭 4,000 文字まで）を送信します。カードの利用先のジャンル推定では、利用先の名前だけを送信し、金額や日付は送信しません。送信した情報は Anthropic の規約とプライバシーポリシーに従って扱われます。
  • Frankfurter（為替レート）：外貨の金額を円に換算するために、為替レートを取得します。メールやカードの情報は送信しません。

上記のほかに、Google から取得した情報を第三者へ提供することはありません。

5. Google API から取得した情報の取り扱い

本アプリによる Google API から取得した情報の利用と他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

6. アクセス権の取り消しと情報の削除

本アプリへのアクセス権は、Google アカウントの設定画面からいつでも取り消せます。PC 内に保存した情報は、本アプリのデータベースを削除すると消去できます。

7. お問い合わせ

Google のログイン画面（同意画面）に表示されるサポートメールアドレスまでご連絡ください。

8. 変更

このポリシーを変更する場合は、このページを更新します。
